# Tu Luz Interior

Simulador para calcular sesiones de limpieza energética y consultar un catálogo de servicios. El proyecto utiliza HTML y JavaScript, e incorpora conceptos de programación orientada a objetos mediante clases, constructores, instanciación de objetos y métodos. También trabaja con funciones, condicionales, ciclos y métodos de arrays.

## Archivos

- `index.html`: página principal del simulador.
- `main.js`: contiene las preguntas, validaciones, cálculos de precios, manejo del catálogo y la implementación de la clase `Servicio
